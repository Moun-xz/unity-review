# 05 · 实验与课设工程

《游戏开发技术》课程四个实验、三次作业与课程设计的 Unity 工程源码。按「实验 / 作业 / 课设」分类，目录名统一为 `类别_主题_学号后四位`。

| 目录 | 内容 |
|---|---|
| `实验/实验1_贪吃蛇_5305` | 2D 贪吃蛇：`Game` / `Snake` / `FoodSpawner`，空格启动、食物刷新与撞墙判定 |
| `实验/实验2_地形与天空盒_5305` | 地形、天空盒、水体与旧村庄场景资源 |
| `实验/实验2_汽车驾驶_5305` | 汽车驾驶：`CarMove` / `CarLife` / `ProcessCollider`，刚体驱动与碰撞 |
| `实验/实验3_台球_5305` | 台球：`Ball` / `BallCreate` / `Hole` / `player`，白球控制与动态生成球组 |
| `实验/实验4_角色动画基础_5305` | 角色移动、跑步与转向，`Controller1` + Animator |
| `实验/实验4_融合树_5305` | `Blendtree` 融合树，`Direction` / `Speed` 参数驱动移动动画 |
| `作业/作业2_台球控制_初版_5305` | `BallShoot` + `FollowCamera`，刚体施力与相机跟随 |
| `作业/作业2_台球控制与收集_5305` | 上一版基础上加入 `PickUp` 与 `GameManager` 计分 |
| `作业/作业3_双人角色对战_5305` | 双角色控制、攻击命中盒、打击反馈与 BGM |
| `课设/课程设计_虚数星区_太空射击_5305` | 课程设计「虚数星区」2D 太空射击，含完整 README、UI 规范与 12 张运行截图 |

## 收录范围

- 收录：C# 脚本、场景、预制体、材质、动画控制器、Shader、项目设置，以及工程内少量自制贴图与音频。
- 未收录：实验指导书与课件、`.unitypackage` 素材包、第三方模型/贴图、视频、压缩包，以及 `Library` / `Temp` / `obj` / `Logs` / `UserSettings` 等 Unity 本地缓存。
- 因此这些工程保留的是**源码与自制资源**，不等同于可直接完整还原的原始素材工程；需要外部素材包时请按原实验资料自行导入。

## 打开方式

用 Unity **2022.3.62f3c1** 打开对应目录（以含 `Assets/`、`ProjectSettings/` 的工程根目录为单位），在 `Assets/Scenes/` 中打开场景后点 Play。课设工程请先阅读其根目录 `README.md`。
