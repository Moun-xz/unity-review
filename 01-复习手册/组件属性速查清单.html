怎么用这份清单：不要背表格，背第三列和第四列。第三列「作用」是答题时的定性句，第四列「设错会怎样」是老师最想看的判断力——案例题里那句“为什么这么设”就从这里出。
每条都标了出处（如 课件05 p4 = Game 05 第 4 页），考场上说“课件上讲过 Rigidbody 的 Mass 是质量”，比含糊地说“我记得好像有个质量参数”要稳得多。

一、Transform每个物体都有，最基础也最容易答漏

Transform变换组件 每个 GameObject 必有且不可删除 课件02 p43 · 课件03 p8
属性 / 方法中文作用与答题用语设错会怎样
position世界坐标物体在世界坐标系中的位置。父子关系存在时，改它是由引擎反算本地坐标父物体旋转后直接改 position，子物体会被“带偏”
localPosition本地坐标相对父物体的位置。UI 和挂点（枪口、头顶血条）一律用它给子物体用 position 做跟随，父物体一动就错位
eulerAngles欧拉角用 (x,y,z) 三个角度表示朝向，直观、可读角度跨 0/360 时插值会“绕远路”转一大圈
localScale缩放相对父物体的缩放倍数，可做“挤压拉伸”动效父物体 scale 为 0 时子物体整个消失，且无法靠改自身救回
RotateAround(point, axis, angle)绕点旋转绕世界空间中某点、某轴旋转指定角度；公转用它（太阳-地球-月亮案例）用 Rotate 做公转，物体会原地自转，位置不变
LookAt(target)朝向目标让物体正前方（Z 轴）对准目标点；炮塔、NPC 面向玩家2D 里用 LookAt 会把物体绕 X 轴翻过去（2D 只有 XY 平面）
Center / Pivot轴心点Center＝包围盒中心，Pivot＝模型自带轴心；只影响编辑器里的操作手感，不改实际坐标以为改了 Pivot 就能改物体位置——不会，运行时毫无影响
一句话答题：Transform 决定物体“在哪、朝哪、多大”，是所有组件里唯一不可移除的；父子关系形成变换层级，子物体的世界变换 = 父变换 × 本地变换。

二、物理：Rigidbody · Collider · 物理材质第 5 章，编程题与案例题双重必考

Rigidbody刚体 3D 课件05 p4~p6
属性中文作用与答题用语设错会怎样
Mass质量决定物体惯性大小。同等的力，质量越大加速度越小（F=ma）台球质量设成 100，一杆打上去纹丝不动
Drag空气阻力平移运动的阻力。0＝无阻力（太空、冰面），值大＝很快停下赛车 Drag 设太大，油门踩到底也提不起速
Angular Drag角阻力受扭矩旋转时的阻力。值极大时物体立即停止转动设成 0，被撞一下能转到天荒地老
Use Gravity受重力是否受场景重力影响（默认 9.81）俯视/太空题材忘了取消，物体会往下掉
Is Kinematic运动学只受 Transform 与动画驱动，不受力影响；仍能与动态刚体产生碰撞事件门想要“能开但撞不飞”，就是勾它；两个 Kinematic 之间不产生碰撞
Interpolate插值平滑帧间的 Transform，消除抖动，一般用于主角/相机这类主要对象。None / Interpolate（按前帧内插）/ Extrapolate（按后帧外插）所有物体都开，白费性能；主角不开，高速移动时会“一顿一顿”
Collision Detection碰撞检测精度Discrete（慢速/静止）/ Continuous（可能与高速物碰撞）/ Continuous Dynamic（本身是高速物）子弹用 Discrete 会直接穿墙——一帧位移超过墙的厚度，检测不到
Constraints约束冻结某些轴的运动/旋转，如 Freeze Rotation Z 防打转、Freeze Position Y 防下坠2D 忘了冻结 Z 旋转，箱子被推着会自己转圈
velocity速度直接读写刚体速度（向量）。改它比 AddForce 更“硬”，适合冲刺、弹跳每帧累加 AddForce 又不用 Drag，速度会失控
常用方法：AddForce() 加力 · AddTorque() 加力矩 · AddForceAtPosition() 点力（同时产生力矩）· Sleep() 休眠 / WakeUp() 唤醒（课件05 p6）。
关键铁律：物理相关代码写 FixedUpdate，不写 Update——FixedUpdate 是固定步长的真实时间，与物理引擎同步（课件02 p30）。
Rigidbody2D2D 刚体 2D · 实验一贪吃蛇 Unity 2022 界面
属性中文作用与答题用语与 3D 的差别
Body Type刚体类型Dynamic（受力运动）/ Kinematic（脚本驱动、不受力）/ Static（完全不动）3D 里这个三档是靠「有无刚体 + Is Kinematic」组合表达的
Gravity Scale重力倍数1＝正常，0＝完全失重3D 是开关（Use Gravity），2D 是倍数，能做“半重力”
Linear Drag线性阻力2D 版的 Drag。2021 起由 Drag 改名为 Linear Drag看旧教程找“Drag”找不到，就是它
Freeze Rotation Z冻结 Z 旋转在 Constraints 里勾选，防止 2D 物体被撞得打转2D 只该冻结 Z，冻 X/Y 会让物体无法移动
Collider碰撞体 最常考的一个勾选框 课件05 p7~p9
属性中文作用与答题用语设错会怎样
Is Trigger触发器勾选＝取消物理阻挡，只做区域检测，进 OnTriggerEnter；不勾＝正常碰撞，进 OnCollisionEnter两个回调互斥，不能同时存在（课件05 p9 原话）。想挡人却勾了它，箱子会被穿过去
Material物理材质指定摩擦和弹性。台球要 Bounciness 高，冰面要摩擦低用默认材质，球撞上去像撞棉花
Center / Size中心/尺寸碰撞体的形状参数，可在 Scene 里拖绿线调人物碰撞体比模型大一圈，走过去会被空气墙卡住
Mesh Collider → Convex凸包勾上变成凸包，代价是凹形内部被填平不勾 Convex 就不能挂动态刚体，会报错
碰撞 vs 触发，判据只有一条（课件05 p8~p9）：
① 发生碰撞的必要条件：一个为刚体，另一个为碰撞体。
② 碰撞且存在力的相互作用：必须两个对象都有刚体。
③ 触发：双方至少一方有刚体即可，勾选一方 Is Trigger 就生效。
④ 静态碰撞体之间永远不会产生碰撞事件——这是新手第一大坑。
⑤ 勾了 Trigger 后刚体物体会下坠穿透，可用 Constraints 约束 Y 方向防止（课件05 p9 原话）。
Physic Material物理材质 注意：它是「资源」不是组件 课件05 p13
属性中文作用与答题用语典型配置
Dynamic Friction动摩擦移动过程中的摩擦力，0~1。0 像冰，1 很快停冰面 0.05 / 橡胶 0.9
Static Friction静摩擦静止时克服的摩擦力，0~1坡道上物体不下滑靠它
Bounciness弹性0 不反弹，1 反弹不损耗能量台球 0.95 / 金属 0.2
Friction Combine摩擦组合两个物体都有材质时怎么算：Average 平均 / Min / Max / Multiply 乘积默认 Average；想“最滑者说了算”用 Min
Bounce Combine反弹组合同上，作用于弹性打砖块里想让球始终高弹，用 Max
四组现成配方（课件05 p13）：冰面＝低摩擦低弹性 · 橡胶＝高摩擦高弹性 · 金属＝中等摩擦低弹性 · 蹦床＝中等摩擦高弹性。

三、场景表现：Camera · Light · Terrain第 3 章，老师录音里点名「地形、灯光都会考」

Camera摄像机 课件01 p52 · 课件03 p22 · 课件08 p6
属性中文作用与答题用语设错会怎样
Field of View视野角度透视相机的张角，60 为默认，值越大越广角、越容易晕FOV 调到 100，边缘拉伸成鱼眼
Projection投影方式Perspective 透视（近大远小）/ Orthographic 正交（无透视，2D 与等距用）2D 游戏用透视，远处的精灵会变形
Clear Flags / Background清屏/背景Skybox 天空盒 / Solid Color 纯色（课件01 p52 案例就改成 Solid Color）/ Depth only两个相机叠加时下层没设 Depth only，会把上层画面擦掉
Depth渲染深度值小的先画。UI 相机 0、游戏相机 -1（课件08 p6 原话）设反了 UI 会被 3D 场景盖住
Culling Mask剔除遮罩决定这个相机只渲染哪些 Layer小地图相机不剔除 UI 层，小地图上会糊一层血条
Target Texture渲染目标把画面输出到 Render Texture 而非屏幕——小地图、监控画面、镜面都靠它（课件04 p21）忘了建 Render Texture，相机拍了没地方放
Plane Distance平面距离Screen Space-Camera 模式下 UI 与相机的距离（课件08 p6）距离小于场景物体，UI 会被模型挡住
相机跟随的两种口径（别混）：讲原理/更稳做法答 LateUpdate（课件02 p32「跟随物体的相机可以在 LateUpdate 里实现」）；代码挖空照实验二与课件03 p27 原文填 Update。理由：LateUpdate 在所有 Update 之后执行，能拿到本帧最终位置，避免“永远差一帧”。
Light光源 必考 课件03 p33~p37
属性中文作用与答题用语设错会怎样
Type类型Directional 平行光（太阳，位置无关只关朝向）/ Point 点光（灯泡，全向）/ Spot 聚光（手电、路灯）/ Area 面光Area Light 不能实时光照，只能烘焙——这是爱考的冷知识
Range范围光照半径。Point 和 Spot 必须调这个参数（课件03 p33 原话）Directional 没有 Range，改它没反应
Intensity强度亮度。室内场景靠它压出明暗层次全靠它提亮会导致过曝、失去阴影
Color颜色光源色。暖黄＝黄昏，冷蓝＝夜晚只调环境光不调色温，画面一片灰
Cookie遮罩贴图带 alpha 的纹理，做出树影、窗格光斑。Spot/Directional 用 2D 图，Point 必须用 Cubemap忘了把贴图的 Alpha Source 设为 From Gray Scale，Cookie 不生效（课件03 p33 原话）
Cookie Size遮罩尺寸缩放 Cookie 投影。只有 Directional 有这个参数在 Point 上找它，找不到
Render Mode渲染模式Auto 自动 / Important 逐像素（重要光源）/ Not Important 顶点级（最快）十几盏灯全设 Important，帧率直接腰斩
Shadow Type阴影类型No Shadows / Hard Shadows 硬阴影（次要光源）/ Soft Shadows 软阴影（主要光源，耗计算）所有灯都开软阴影，性能扛不住
Strength / Resolution阴影强度/分辨率阴影黑度和贴图精度Resolution 太低，阴影边缘呈锯齿块
Bias偏移灯控像素位置与阴影贴图比较的偏移，范围 0~0.5过小→物体表面出现 self-shadow 黑斑；过大→阴影严重偏离物体（课件03 p35 原话）
Culling Mask剔除遮罩只照亮指定 Layer 的物体角色层被排除，人物站在灯下是黑的
Mode（Baked/Realtime/Mixed）烘焙模式Mixed 表示静态物体用烘焙、非静态用实时（课件03 p37 原话）全设 Baked，移动的角色走过不会有影子
烘焙四步（课件03 p37，直接当答题步骤写）：① 保存场景 → Edit ▸ Project Settings ▸ Player ▸ Other Settings，Color Space 改 Linear；② Window ▸ Rendering ▸ Lighting Settings，新建并选中 Baked Lightmap 设置；③ 方向光 Mode 设 Mixed(Baked)，场景中不动的物体勾上 Static（运行时无法运动）；④ 点 Generate Lighting 生成资源。
Terrain地形 必考 · 代码少但操作步骤多 课件03 p11~p19
属性 / 操作中文作用与答题用语要点
Set Height / Flatten设定高度/压平Flatten 整体设置高度，可提前整体抬升做湖泊（课件03 p14）做湖：SetHeight 设 10 → Flatten 抬升 → Raise/Lower，Shift 是下陷
Paint Texture → Layer → Create绘制贴图创建图层，第一层是基础层，后续可叠加雪山、砂石、道路；Replace 可整体替换创建图层会自动生成对应资源文件
Brush Size / Opacity笔刷大小/不透明度不透明度类似“压力”，控制单次落笔强度压着不动会一直往下陷
Smooth（Blur Direction）平滑方向 0 全处理，-1 只处理突出部分，1 只处理凹进部分课件写作 Blue Direction，实为 Blur（模糊）
Pixel Error像素容差地形像素容差，越小地形越逼真、开销越大调太小，大场景地形吃满显存
Base Map Dist基础贴图距离超出距离的远地形用低清贴图，牺牲远景换性能调太大，远处地形也在画高清图
Detail Distance / Density细节距离/密度花草离镜头超过距离不再绘制；密度默认 1，调小则过密的细节不绘制草地场景最先该压的就是这两个
Tree Distance树木距离超过该距离的树不被绘制树林卡顿，先调它和 LOD
Cast Shadows投射阴影地形是否产生影子大面积地形开影，烘焙时间暴涨
WindZone风区Mode＝Spherical 球形（仅影响半径内，由中心向外衰减）/ Directional 方向（影响整个场景某一方向）；Radius 半径；Wind Main 主风（柔和变化）；Turbulence 紊流（瞬息万变）树动了草没动，是没给细节对象设风的影响
导入环境包报错怎么办（课件03 p12 原话）：只修版本相关的错误，其余直接 Clear 清除即可。这句话很适合写进“遇到问题怎么处理”的答案里。

Cast Shadows是否投射阴影

Material材质 三层关系必背 课件04 p16 p23 p24
属性中文作用与答题用语设错会怎样
Shader着色器决定材质的渲染算法，是“质感的算法来源”选到 Unlit 类，物体不再受光，怎么打灯都不亮
Main Color / Albedo主色材质球的基础颜色，与贴图相乘颜色设成灰色，白底贴图整个被压暗
Base (RGB) / Main Tex基础贴图主纹理，表现基础颜色与花纹—
Normal Map法线贴图用像素记录法线方向，模拟表面凹凸，不增加多边形当普通贴图用（Texture Type 没选 Normal Map），凸起方向全错
Height Map高度贴图视差效果的深度信息，近处细节更“立体”—
Specular / Gloss高光控制表面光滑程度，金属、瓷器靠它木头也调高光，看起来像塑料
三层关系一句话（课件04 p16 原话）：材质包含贴图，贴图包含纹理。纹理是最基本的数据输入单位（位图）；贴图额外包含 UV 坐标与输入输出控制；材质是数据集，由 Shader 实现。
四类材质分类（课件04 p24）：漫反射 Diffuse / 凹凸漫反射 Bumped Diffuse（多一张 normal map）/ 高光 Specular / 凹凸高光 Bumped Specular。
铁律：Unity 内置对象的默认材质无法修改，要改必须先新建材质再拖上去（课件04 p23）。

五、声音：Audio Source · Audio Listener第 3 章，编程题必考方向之一

Audio Source音频源 必考 课件03 p40~p44
属性中文作用与答题用语设错会怎样
Audio Clip音频剪辑要播放的声音文件。长背景音乐用 mp3 / ogg，短音效用 wav / aiff音效存成 mp3，起点有编码延迟，打击感全毁
Play On Awake唤醒即播场景加载就播；取消则必须用脚本 Play() 启动想做按键触发音效却忘了取消，一进场景全响一遍
Loop循环播完自动重头，BGM 必开音效开了 Loop，一次爆炸响个不停
Volume音量0~1 范围（脚本里赋 0.2f 也是这个区间）按 0~100 去赋值，全部被钳到 1
Pitch音调加速/减速播放。随机 ±0.1 可让重复音效不呆板Pitch 调太低，音效变成慢放怪声
Stereo Pan左右声道2D 声音的左右偏移—
Spatial Blend空间混合拖到 2D＝不随距离衰减（BGM、UI 音效）；拖到 3D＝在 Min/Max Distance 之间近大远小BGM 设成 3D，走远了就没声了
Min / Max Distance最小/最大距离Min 之内保持最响，Min 之外开始衰减；超过 Max 停止衰减。调大 Min 可让声音在 3D 世界更响Min 设 1，站两米外就听不清
Spread / Doppler Level扩散/多普勒扬声器空间传播角度 / 移动声源的高低音变化赛车开普勒拉满会听出“电子音”
Load Type加载方式Decompress on Load（短音效，占内存不占 CPU）/ Compressed in Memory（中等）/ Streaming（长 BGM，边播边读）BGM 用 Decompress on Load，进场景卡一下
脚本常用（课件03 p44）：audio.isPlaying 判在播 · audio.loop = true · audio.volume = 0.2f · Play() / Stop() · Resources.Load<AudioClip>("Brightman") 动态加载。
Play 与 PlayOneShot 的区别：Play() 会打断当前正在播的同一个音源；PlayOneShot(clip) 可叠加播放，适合连发枪声、多次撞击。
Audio Listener：挂在相机上，相当于“耳朵”，一个场景只能有一个，多了会报警告（课件03 p40）。

六、特效与动画：Particle System · Animator第 6、7 章，录音点名两项

Particle System粒子系统 模块化，按六大类记 课件06 p6~p14
模块中文作用与答题用语
基础模块MainDuration 持续、Looping 循环、Start Lifetime 生命周期、Start Speed、Start Size、Start Color、Simulation Space（Local/World）、Max Particles

Shape形状模块发射器的形状：Sphere 球 / 半球 / Cone 锥 / Box 盒 / Mesh 网格。改它决定粒子从哪儿飞出来
Sub Emitters子发射器给粒子再加发射器（爆炸的碎片再冒烟），分 Birth / Collision / Death 三种触发时机
Velocity over Lifetime生命周期速度粒子存活期间改速度——可做减速、绕圈
Limit Velocity over Lifetime限速控制粒子最大速度，防止飞太远
Force over Lifetime生命周期力持续施加力，可做上升的烟雾、飘落的灰烬
Color over Lifetime颜色渐变从亮黄→橙→透明黑，是火焰/爆炸的灵魂
Size over Lifetime大小渐变先大后小＝消散，先小后大＝膨胀
Rotation over Lifetime旋转渐变让碎片翻滚
Color / Size / Rotation by Speed按速度满足速度条件才执行，用于尾焰、冲刺拖影
Texture Sheet Animation帧动画让粒子播序列帧，做成翻页式爆炸
Noise噪音给粒子加不规则运动，风中的烟、雪花
Trails拖尾显示粒子运动轨迹，流星、子弹
Inherit Velocity速度继承继承父物体的移动速度。需要把 Simulation Space 改为 World（课件06 p13）
External Forces外力配合 Particle System Force Field 组件用（风、吸引力）
Collision / Triggers碰撞/触发粒子撞到物体后的表现 / 进出触发器区域时的效果
Lights粒子光照给粒子加实时光，让爆炸照亮周围
必背的那句对比（课件06 p11 原话）：over Lifetime 类似花开花落的一生——从头到尾持续变化；by Speed 类似跑龙套——当满足条件才执行。
数值设置三种（课件06 p6）：① 权重（0~1）② 固定参数 ③ 参数曲线——粒子系统千变万化的根源。
代码控制：Play() 播放 / Stop() 停止 / Clear() 清空已有粒子。
Animator动画组件 参数类型是常考点 课件07 p8~p25
属性 / 方法中文作用与答题用语
Controller动画控制器指定 Animator Controller 资源，不挂它角色就是“植物人”
Avatar替身人形骨骼映射，是动画复用（Retargeting）的前提：同一套动作给不同模型用

SetFloat / SetBool / SetInteger / SetTrigger设参数向状态机传值。类型必须与 Controller 里定义的一致：整数参数用 SetFloat 设置，动画机一声不响什么都不做
参数类型：Trigger vs Bool触发 vs 布尔Trigger 触发一次自动复位，适合跳跃/攻击；Bool 保持状态，适合跑/走。用 Bool 做攻击会连续触发，用 Trigger 做跑步会跑一步就停

Loop Time / Loop Pose / Bake Into Pose循环设置勾上保证动作首尾衔接平滑；LoopMatch 显示绿色说明匹配成功（课件07 p13）

九宫格（课件写作「切片」，课件08 p10 原话「ImageType：普通、切片、平铺、过滤填充」）：解决的是图片拉大后四角变形、边框变粗。做法是在 Sprite Editor 里拖出四条 Border 边界把圆角框住，再把 Image Type 设成切片——四个角保持原始像素不动，只让四条边单向拉伸、中间双向拉伸。一张 100×100 的小图能撑出全屏对话框。取消 Fill Center 则只画边框、中间透空，做暂停面板最省事。
2D 里同样能用：Sprite Renderer 的 Draw Mode 选 Sliced，就能做任意拉长但两端不糊的激光柱、平台、管子。

八、最容易答错的 12 处这 12 条就是案例题里的「判断力」

1Is Trigger 不是“两边都勾才生效”——勾一方就够了，一旦勾上就不再产生物理阻挡，OnCollision 与 OnTrigger 互斥。
2静态碰撞体之间永远不产生碰撞事件——必须至少一方有刚体。地面不挂刚体是为了省性能，人物挂刚体就够（课件05 p9 原话）。
3Inspector 右上角的 Static 不是物理开关——它管的是光照烘焙、遮挡剔除、静态批处理，和“物体会不会被推动”无关。
4物理代码写 FixedUpdate，不是 Update。FixedUpdate 是固定步长的真实时间，与物理解算同步。
5相机跟随后写 LateUpdate 更稳（能拿到本帧最终位置），但实验二原文写的是 Update——考代码挖空照原文填。
6Area Light 不能实时光照，只能烘焙。这题几乎年年有。
7Cookie 贴图必须把 Alpha Source 设为 From Gray Scale，否则拉了图也没效果（课件03 p33）。
8烘焙前必须把 Color Space 改成 Linear，且参与烘焙的物体要勾 Static，最后点 Generate Lighting。
9Mesh Collider 不勾 Convex 就不能挂动态刚体；建筑这类复杂模型用多个 Box Collider 拼比 Mesh Collider 快得多。
10Play() 会打断，PlayOneShot() 会叠加。连发枪声用后者，BGM 切换用前者。
11Animator 参数类型要对：整数参数必须用 SetFloat 也是不行的——类型不匹配时编译不报错、运行没反应，最难查。
12Overlay 模式不能改 Canvas 的 XY；UI 控件必须是 Canvas 子对象；一个场景只能有一个 EventSystem。
