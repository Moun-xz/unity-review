第 1 章 概述8 条

1. 什么是游戏？它的两个基本特性是什么？高频
游戏是以直接获得快感为主要目的，且必须有主体参与互动的活动。
两个基本特性：① 以直接获得快感（包括生理和心理愉悦）为主要目的；② 主体参与互动，指主体动作、语言、表情等变化与获得快感的刺激方式及刺激程度有直接联系。
易错：是「主体参与互动」，不是「主动参与互动」。
2. 什么是游戏引擎？技术栈的层次是什么？高频
游戏引擎是已编写好的可编辑游戏系统，或者一些交互式实时图像应用程序的核心组件。这些系统为游戏设计者提供编写游戏所需的各种工具，目的在于让设计者容易、快速地做出游戏程序而不用从零开始。
技术栈层次（背这条链）：Game → Game Engine → SDK → DirectX/OpenGL → GPU。
3. Unity 与 Unreal 的区别（六条）？
① Unity 用 C#，Unreal 用 C++ 和 Blueprint；② UE 在光影、纹理、材质等渲染效果上更好；③ Unity 社区更大、更易上手；④ Unity 在 2D 游戏与移动端更有优势；⑤ UE 的可定制性更高；⑥ UE 更适合制作大型 3A 游戏（代价是三个"贵"：钱、资源、时间）。
4. 三种渲染管线分别适合什么？高频
内置渲染管线（Built-in）：默认渲染管线，适用于原型设计或对画质要求不高的游戏，适用于低端设备。
通用渲染管线（URP）：对平台支持广泛，性能表现较好，适合移动端、桌面端、网页端。
高清渲染管线（HDRP）：适合大型 3A 游戏，有高清渲染需求，适合桌面和主机项目。
5. Unity 的坐标系是什么？三个轴指向哪里？
左手坐标系。设计角度和运行角度都是：X 向右、Y 向上、Z 向前。
对应常量：X → Vector3.right / left；Y → up / down；Z → forward / back。
6. Scene 视图的 Persp 与 ISO 有什么区别？
Persp（透视）：近的物体显示得大，远的显示得小。
ISO（平行视野）：不论物体离摄像头远近，给人的感觉一样大。
注意：在 Game 界面两种模式呈现效果是一样的，区别只在编辑场景界面；开发时在 Persp 下比较好。
7. 五个内置模型的尺寸是多少？高频
Sphere：半径 r = 0.5（直径 1）　Cube：1 × 1 × 1
Capsule：h = 2 + 0.5 + 0.5 = 3（中间圆柱 2，上下半球各 0.5）
Cylinder：h = 3　Plane：边长 10
Quad：XY 平面，只有 2 个三角形
8. 项目迁移要拷贝哪些文件夹？
只需拷贝 Assets 和 ProjectSettings，其他可以不拷贝。
ProjectSettings 文件夹对应 Edit 菜单下的 Project Settings 相关设置；它在磁盘上，Project 面板里看不到。

第 2 章 C# 与 Unity 脚本基础10 条

9. MonoBehaviour 生命周期方法的执行顺序？今天错高频
Reset → Awake → OnEnable → Start → FixedUpdate → Update → LateUpdate → OnGUI → OnDisable → OnDestroy
各方法的作用（PPT 原话）：
Reset：重置函数，对象加载脚本时调用　Awake："唤醒"事件函数　OnEnable："脚本启用"事件函数
Start：开始函数　FixedUpdate：固定步长更新函数（物理状态相关的更新）
Update：更新函数　LateUpdate：延迟更新函数（相机相关的更新；但实验二代码写的是 Update，见第 11 题）
OnGUI：界面绘制函数　OnDisable：禁用脚本函数　OnDestroy：销毁函数
10. Awake 与 Start 的区别？今天错
① 时机：Awake 在对象被加载（实例化）时立即调用，早于所有 Start；Start 在第一次 Update 之前调用。
② 受 enabled 影响：Awake 不受影响（脚本被禁用也执行）；Start 受影响（脚本未启用则不执行）。
③ 用途：Awake 初始化自己身上的引用；Start 使用其他对象已初始化好的数据。
11. FixedUpdate、Update、LateUpdate 的区别？高频
Update 和 FixedUpdate 都在每一帧被调用，但两者帧长不同。Update 跟当前平台的帧数有关。
FixedUpdate 是真实时间，处理物理逻辑（例如 Rigidbody）时要把代码放这里，例如给刚体加作用力。时间间隔在 Edit → Project Settings → Time → Fixed Timestep 中修改。
LateUpdate 在所有 Update 函数调用之后被调用。跟随物体的相机一般放在 LateUpdate 里实现。
为什么能防抖：两个脚本同时在 Update 里控制同一物体，方位会出现反复；跟随者在 Update 里跟就会抖动，放 LateUpdate 会等所有 Update 执行完再动。
⚠ 老师课件里两处出处不一致（必看）
① 课件 02 slide 32（讲原理）：「跟随物体的相机可以在 LateUpdate 里实现」；
② 课件 03 slide 27（相机 demo 代码）与实验二：写的是 void Update()。
→ 考原理 / 为什么 / 更稳的做法：答 LateUpdate（等所有 Update 跑完再跟，不会永远差一帧）。
→ 考代码挖空：照代码原文填 Update。两个都记住，别只背一个。
12. 什么是协程？为什么需要它？高频
Unity 脚本只支持单线程，所以引入 C# 的协程概念。协程在协调多帧中执行的操作时有用处，并且性能开销小。
StartCoroutine()：开启协同程序函数，协程结束返回。
yield return：是迭代器返回调用迭代的地方，一个协程的执行可以在任何地方用 yield 语句暂停，yield return 的值决定了什么时候协程恢复执行。
注意：协程不是线程，它是在主线程上分帧执行的。
13. yield return 的几种写法各是什么含义？
yield return null; → 暂停，下一帧再继续往下执行
yield return new WaitForFixedUpdate(); → 等到下一次调用 FixedUpdate 时继续
yield return new WaitForSeconds(k); → k 秒后再继续
yield return StartCoroutine("Other"); → 暂停，直到另一个协程结束
yield return new WaitForEndOfFrame(); → 等到这一帧渲染结束
14. GameObject 的常用方法有哪些？高频
继承自 Object。
AddComponent<T>() 加组件　GetComponent<T>() 取组件（不带前缀 = 查自己这个物体）
CreatePrimitive()：静态方法，创建原始类型游戏对象
Find() 查找游戏对象　FindGameObjectsWithTag() 查找游戏对象（多个）
Destroy() 销毁　Instantiate() 克隆对象
15. Transform 的三个核心方法与旋转方向规则？高频
属性：position、eulerAngles、localScale（每个游戏对象都有 Transform）。
RotateAround(point, axis, angle)：point 是要围绕的点，axis 是围绕的轴，angle 是角度。
Rotate(eulerAngles, Space)：第二参数 World / Self。
Translate(translation, Space.Self)：第二参数默认是 Space.Self。
方向规则：若旋转轴是 X，则从 X 轴正方向看，物体顺时针旋转。
16. 场景加载的同步与异步有什么区别？
Application.LoadLevel() 同步加载：读取速度最快，但不更新界面，因为同步执行时程序在等待读取结束。读取时间过长会让用户以为卡死。
LoadLevelAsync() 异步加载：读取时界面可以有动画，Update 每帧都执行。
属性：isDone 查询是否加载完成；progress 是 0~1 之间的加载进度。
注意：加载前要在 Build 中把场景添加进去。
17. 跨场景传数据有哪两种方式？
① 静态变量：public static int age = 20;，在另一个场景里直接 Scene1.age 读取。
② DontDestroyOnLoad：在 Start 函数中写 GameObject.DontDestroyOnLoad(gameObject);，让该物体切场景时不被销毁。
18. 建立脚本有哪些注意事项？
① 文件名与类名要一致；② 脚本依附游戏对象或被其他脚本调用；③ 初始化放在 Start 方法中；④ 可在 Inspector 窗口修改 public 属性，但运行中修改不会保存；⑤ 工程要分层设计（_Scripts、_Scenes 等）。

第 3 章 Unity 资源系统11 条

19. 设置天空盒的三种方式？高频
方法 1 静态添加：为 Camera 添加 Skybox 组件，设置新材质。
方法 2 脚本赋值（不能给相机加 Skybox 组件）：材质要放到 Resources 文件夹下，否则找不到。
RenderSettings.skybox = (Material)Resources.Load("skybox1");
方法 3 脚本赋值（必须给相机加 Skybox 组件）：
GetComponent<Skybox>().material = (Material)Resources.Load("skybox1");
易错：方法 2 如果多加了 Skybox 组件，空材质会覆盖全局设置，天空盒反而不显示。另：Resources.Load 不带扩展名。
20. 相机的 Clear Flags 有哪几种？高频
Clear Flags 确定屏幕哪些部分将被清除。
Skybox：屏幕上任何空的部分将显示当前相机的天空盒。
Solid Color：任何空部分显示为当前相机的背景色（Background）。
Depth only：只清深度，保留颜色（多相机叠加用）。
Don't Clear：什么都不清。
21. 正交与透视投影分别有什么参数？
Orthographic（正交）：相机均匀地渲染物体，没有透视感；参数是 Size，表示摄影机视口的大小。
Perspective（透视）：使物体和透视完好无损；参数是 Field of view，相机的视野，沿着本地 Y 轴测量。
Clipping Planes：Near 是绘制的最近点，Far 是最远点，过大会造成精度下降。
22. Unity 有哪四种光源？哪一种不能实时？今天要答案高频
Directional Light（方向光）：类似太阳的日照效果。
Point Light（点光源）：类似电灯泡、爆炸效果。
Spot Light（聚光灯）：类似手电筒，模拟路灯壁灯。
Area Light（区域光）：无法用作实时光照，一般用于光照贴图烘焙，必须烘焙，物体必须静态。用于建立柔和的照明效果。
23. 光源的关键属性（Range / Cookie / Cookie Size / Bias）？
Range：光源范围大小，Point 和 Spot 必须调整该参数。
Cookie：为光源设置拥有 alpha 通道的纹理，使光线在不同地方有不同亮度。Spot 和 Directional 指定 2D 纹理；Point 须指定 Cubemap。Cookie 图片的 Alpha Source 要设置成 From Gray Scale。
Cookie Size：控制缩放 Cookie 投影，只有 Directional Light 有该参数。
Bias：灯光控件像素位置与阴影贴图值比较的偏移量，取值 0 ~ 0.5。值过小对象表面会产生 self-shadow；值过大阴影会较大程度偏离投影的对象。
24. 光源的 Shadow Type 与 Render Mode 有哪些？
Shadow Type：No Shadows 关闭；Hard Shadows 硬阴影（次要光源）；Soft Shadows 软阴影（主要光源，耗计算）。
Render Mode：Auto 根据光源亮度与 Quality Settings 自动确定；Important 逐像素渲染，用于非常重要的光源；Not Important 总是以最快的速度渲染。
Culling Mask：选中层所关联的对象将受到光源照射。
25. 音频格式与加载类型（Load Type）怎么选？高频
格式：mp3 / ogg 用于较长的背景音乐；wav / aiff 用于较短的音效。
Decompress on load（加载时解压缩）：加载后解压缩声音，适用于较小的压缩声音。
Compressed in memory（内存中压缩）：保持压缩在内存中，播放时解压缩，大文件使用。
Stream from disc（磁盘流）：直接从磁盘流读取音频数据，适用于很长的音乐。
易错：是 Disc 不是 Disk。
26. Audio Listener 有几个？在哪？
由摄像机的 Audio Listener 组件进行监听，相当于"耳朵"，一般一个场景只有一个 Listener。
27. 地形（Terrain）的几个关键设置？
Detail Distance（细节距离）：当地形细节花草离镜头超过这个距离时，就不会被绘制在屏幕上。
Detail Density（细节密度）：默认 1，调小则过密的地形细节不被绘制。
Tree Distance（树木距离）：超过这个距离的树木不会被绘制。
Max Mash Trees：可种植的树木上限。
Pixel Error（像素容差）：容差越小，地形越逼真。
Base Map Dist：为了减少性能消耗，镜头远处的贴图会看起来不清晰。
28. 地形笔刷的操作规律？
抬升（单击）、下陷（单击 + Shift，需先 SetHeight）；
放置树木 / 花草（单击）、清除（单击 + Shift）、清除指定（单击 + Ctrl）；
Brush Size 是绘制的面积，Opacity 是绘制的高度，Target Strength 是绘制的密度。
湖泊做法：SetHeight 设置高度 → Flatten 整体抬升 → Raise/Lower，Shift 降低。
29. WindZone 的两种模式？
Spherical（球形）：风区仅影响半径内，从中心朝向边缘衰减。
Directional（方向）：风区会影响整个场景的一个方向。
另：Wind Main 主风产生风压柔和变化；Turbulence 紊流产生瞬息万变的风压；Pulse Magnitude / Frequency 是脉冲幅度与频率。

第 4 章 3D 数学与 3D 图形学14 条

30. 点乘的公式与三个判定区间？今天忘写过程高频
坐标公式：v1·v2 = x1x2 + y1y2 + z1z2，用 Vector3.Dot(v1, v2) 完成。
几何公式：v1·v2 = ||v1|| ||v2|| cosθ，θ = arccos(v1·v2)（单位向量时）。
判定：v1·v2 > 0 时 0 ≤ θ < 90°（前方）；= 0 时 θ = 90°（垂直）；< 0 时 90° < θ ≤ 180°（后方）。
判方位的写法（必须写全三步）：
// ① 两个对象间的向量（从 obj1 指向 obj2）
Vector3 v = obj2.transform.position - obj1.transform.position;
// ② obj1 自己的前方（自身坐标转世界坐标）
Vector3 wforward = obj1.transform.TransformDirection(Vector3.forward);
// ③ 点乘判符号
if (Vector3.Dot(wforward, v) < 0) print("obj2 在 obj1 后方");
else                              print("obj2 不在 obj1 后方");
31. 叉乘的公式、反交换律与用途？今天完全不会高频
公式（三个分量，注意中间那个顺序不同）：
v1 × v2 = v3 ( y1z2 − z1y2 , z1x2 − x1z2 , x1y2 − y1x2 )
反交换律：v1 × v2 = −(v2 × v1)。
几何意义：v3 同时垂直于 v1 和 v2，用于计算一个平面的正面朝向。
长度：|v1 × v2| = ||v1|| ||v2|| sinθ，所以求法线后必须单位化。
// 求三角面的法线：两条边必须从同一个顶点出发
Vector3 side1  = objc.transform.position - obja.transform.position;
Vector3 side2  = objb.transform.position - obja.transform.position;
Vector3 normal = Vector3.Cross(side1, side2);
normal.Normalize();   // 单位化
32. magnitude 与 sqrMagnitude 的区别？今天答一半
magnitude 是向量的模（长度）；sqrMagnitude 是不开方的值（长度的平方）。
常用：计算两个对象之间的距离 (v1 - v2).magnitude。
只用平方的场景：只做大小比较时（长度与它的平方同增同减），省一次开方。
坑：用 sqrMagnitude 比阈值时，阈值也要平方——dir.sqrMagnitude < 9f 才等于 3 米，写成 < 3f 实际只剩 1.73 米。
33. 向量的单位化是什么？有什么用？
单位化：vNormal = v / ||v||，化为大小为 1 的向量，用 Vector3.Normalize(v1) 或 .normalized。
用途：关注方向信息，忽略大小。
向量运算还要记：标量与向量相乘 v1*k = (x*k, y*k, z*k)，常用于缩放。
34. 向量加法和减法在位置上分别代表什么？
如果 v1 代表点的位置：
加法 v1 + v2 表达从一个点，根据 v2 的方向和大小进行移动；
减法 v1 − v2 表达一个对象到另一个对象的方向和距离。
35. 自身坐标与世界坐标如何互相转换？
自身 → 世界：transform.TransformDirection(Vector3.forward)
世界 → 自身：transform.InverseTransformDirection(Vector3.forward)
用途：拿物体自己的前方去和世界坐标下的方向做点乘，判断前后。
36. 模型由什么组成？为什么不能无限加面？
模型由三边面（三角形）组成，边由两个顶点组成。
多边形的数量和顶点数决定渲染效果，需要在效率和效果之间平衡。
37. Mesh Filter 与 Mesh Renderer 各负责什么？今天 (2) 不会高频
网格过滤器（Mesh Filter）：从资源中拿出网格，并将其传递给网格渲染器用于屏幕渲染。
网格渲染器（Mesh Renderer）：负责把网格绘制到屏幕上。
另外两个渲染器：文本渲染器（Text Mesh Renderer）、蒙皮网格渲染器（Skinned Mesh Renderer）。
推论：删掉任一个物体都看不见——网格渲染器不存在时，网格仍存在于场景中，但不能进行绘制。
38. 蒙皮模型导入时 Unity 会自动创建什么组件？
在导入网格资源时，如果该网格是蒙皮的，Unity 会自动创建一个蒙皮网格渲染器；如果不是，则创建一个带网格渲染器的网格过滤器。
如需在场景中查看网格，要将网格渲染器添加到游戏对象上；它是自动添加的，删除后需手动添加。
39. 纹理、贴图、材质三者的关系？今天漏功能说明高频
层次：材质 Material 包含贴图(Map)，贴图包含纹理(Texture)。
纹理：最基本的数据输入单位，游戏领域基本上都用的是位图，此外还有程序化生成的纹理 Procedural Texture。
贴图：包含了另一层含义就是"映射"——把纹理通过 UV 坐标映射到 3D 物体表面。贴图包含了除纹理以外其他信息（UV 坐标、贴图输入输出控制等）。
材质：是一个数据集，是给渲染器提供数据和光照算法。贴图就是其中数据的一部分，根据用途不同贴图会被分成不同类型。
40. 贴图的大小、类型与三种特殊贴图？
大小：Unity 对导入的图默认缩放为 2 的幂次方。
格式：psd、tiff、tga、jpg、png、bmp。
类型：Texture（普通）、Normal Map（法线）、GUI、Sprite 2D and UI、Cursor、Cookie、Lightmap、Cubemap。
Cubemap（立方体贴图）：类似 Skybox，用于模拟物体对环境的反射效果。
Render Texture（渲染贴图）：用于实时监控录像、导航地图等（类似小窗口预览），贴图是动态的，内容由场景中的摄像机获取。
视频贴图：Plane 加 Video Player 组件，用于过关画面。
41. 材质丢失会怎样？材质有哪些分类？
若丢失材质，物体显示紫色。
Unity 内置对象的默认材质无法修改。
分类：漫反射（Diffuse）光线沿各个方向反射回去；凹凸漫反射加一张 normalmap 法线贴图模拟凹凸；高光（Specular）加高光颜色使表面更光滑；凹凸高光；视差漫反射深度模拟更真实；视差高光；透明模拟水或玻璃，用带 Alpha 通道的 Base Trans 控制；自发光通过 Illumin 贴图设置。
Shader：材质由着色器实现，ShaderLab（CG 的二次简化）调用 Direct3D 或 OpenGL 实现 GPU 控制。
42. 网格合并要注意什么？
用 GetComponentsInChildren<MeshRenderer>() 取材质（用 sharedMaterial），用 GetComponentsInChildren<MeshFilter>() 取网格（用 sharedMesh + localToWorldMatrix 把自身坐标转世界坐标），再用 CombineMeshes(combine, false) 合并。
比例失真：如果以某个组件为根物体，它的缩放比例直接影响合并后生成的新物体，各个部件的缩放比都会按它走——所以根物体 Scale 要为 1。
43. 平滑转向的四个步骤（Quaternion 四方法）？今天填空不会高频
① 算方向：Vector3 dir = target.position - transform.position;
② 方向 → 目标旋转：Quaternion.LookRotation(dir)（参数是方向向量，不是目标位置）
③ 平滑过渡：Quaternion.Slerp(当前, 目标, 进度)，Slerp 是球面线性插值，转角均匀；Quaternion.Lerp 走直弦，两端慢中间快
④ 位置插值：Vector3.Lerp(当前位置, 目标位置, 速度 * Time.deltaTime)
另两个：Quaternion.Euler(x,y,z) 欧拉角转旋转；Quaternion.identity 无旋转。
易错：Slerp 的第三参数是比例（0~1），要乘 Time.deltaTime；要严格匀速得用 Quaternion.RotateTowards（第三参数是角度）。

第 5 章 物理系统13 条

44. Unity 用的是什么物理引擎？能模拟什么？
Unity 内置 NVIDIA 公司的 PhysX 物理引擎，采用硬件加速进行模拟物理运算。
可模拟刚体碰撞、车辆驾驶、布料、重力等物理效果。Unity 内置 3D 物理引擎和 2D 物理引擎。
45. Rigidbody 的核心属性？高频
Mass 质量　Drag 空气阻力（0 没有阻力，极大时对象会停止）
Angular Drag 受扭矩力旋转时受到的阻力　Use Gravity 使用重力
Constraints：用于约束物理引擎对于刚体运动的控制（如 FreezePositionY）。
46. Is Kinematic 是什么？今天用反了
是否受物理引擎驱动——受 transform 影响，不受 force 影响。勾选后表示只受脚本和动画影响，不能调用物理计算。
含义：它会推动别的刚体，但自己不会被推；仍然能检测碰撞/触发。
用途：移动平台、铰链门（常勾选 Is Kinematic 固定位置）。
47. Interpolate 三种模式分别是什么？
插值用于控制运动抖动、达到平滑，一般用于主要对象。
None：没有插值。
Interpolate：内插值，基于前一帧的 Transform 来平滑此次的 Transform。
Extrapolate：外插值，基于下一帧的 Transform 来平滑此次的 Transform。
48. Collision Detection 三种模式怎么匹配？高频
Discrete（离散）：与场景中其他所有碰撞体进行碰撞检测，用于慢速和静止对象。
Continuous（连续）：用于可能与高速对象碰撞的对象（被撞的一方）。
Continuous Dynamic（连续动态）：用于可能发生碰撞的高速对象（自己高速）。
目的：防止物体嵌入其他物体。
49. Rigidbody 的常用方法？
Sleep() 刚体休眠　WakeUp() 唤醒刚体
AddForce() 给刚体一个力，使其运动
AddTorque() 给刚体一个力矩，使其旋转（围绕 vector3 旋转）
AddForceAtPosition() 在刚体上应用点力（同时产生力矩和力）
属性：velocity 速度、detectCollisions 碰撞检测开关。
50. 碰撞发生的必要条件是什么？（两个层次）今天只答一半极高频
前提：碰撞体要与刚体一起添加到游戏对象上才能触发碰撞。没有碰撞体的刚体会彼此相互穿过。
① 发生碰撞的必要条件：必须一个为刚体，另一个为碰撞体。
② 不但有碰撞、且存在力的相互作用：必须两个对象都有刚体。
推论：地面可以不设置刚体（它永远不动），只给人物设刚体就能实现真实物理碰撞——减少刚体可以降低资源消耗。
易错：第一句说的是"一个刚体 + 一个碰撞体"，不是"两个都要刚体"；那是第二句的要求。
51. Collision 与 Trigger 的区别（四条）？今天 0 分极高频
① 前提：OnCollisionEnter 必须是在碰撞物体不勾选 IsTrigger 的前提下才能进入；勾选 IsTrigger 就能进入 OnTriggerEnter。两者冲突，不能同时存在。
② 刚体要求：OnCollisionEnter 要求碰撞的发起方必须拥有刚体，而被碰撞方有没有刚体并不重要；OnTriggerEnter 只需要碰撞双方有一个具有刚体即可触发。
③ 回调：Collision 用 OnCollisionEnter/Stay/Exit(Collision other)；Trigger 用 OnTriggerEnter/Stay/Exit(Collider other)。
④ 物理反应：Collision 有阻挡、反弹；Trigger 取消碰撞的阻挡作用，只检测对象是否进入区域。
参数区别：Collision 类包含接触点、碰撞速度等信息；Collider 只有碰撞体本身。
52. Is Trigger 的副作用与透明墙技巧？
Is Trigger 后刚体物体会下坠穿透物体，可约束 Y 方向防止下坠。
技巧：空对象 + BoxCollider + Mesh 实现透明墙。
代码要点：col.gameObject.name.Equals("Player")、GetComponent<MeshCollider>().enabled = true。
53. 物理材质（Physic Material）是组件还是资源？易与材质混高频
物理材质是控制游戏对象的摩擦力和反弹系数等属性的一种资源，不是组件。
使用时赋值给碰撞体组件的 Material 属性。
Dynamic Friction（动态摩擦力）：物体移动时的摩擦力，通常 0~1。值为 0 的效果像冰，设为 1 时物体运动将很快停止。
Static Friction（静态摩擦力）：物体静止克服的摩擦力，0~1。
Bouncyness（弹力）：0 时不发生反弹，1 时反弹不损耗能量。
Friction Combine：Average（平均）/ Min / Max / Multiply；Bounce Combine 同理。
54. 冰面、橡胶、金属、蹦床分别怎么配？高频
冰面：低摩擦，低弹性　　橡胶：高摩擦，高弹性
金属：中等摩擦，低弹性　蹦床：中等摩擦，高弹性
55. 五种关节分别用于什么？高频
关节组件在线框模式下可见黄色标记。
铰链关节（Hinge Joint）：用于制作铰链门、钟摆等。
弹簧关节（Spring Joint）：模拟两个刚体的松散链接关系。
固定关节（Fixed Joint）：模拟两个刚体相互附着，如墙上的钉子与粘贴物，类似游戏中的父子对象。
角色关节（Character Joint）：主要用于表现布娃娃效果，是扩展的球关节，可限制每个轴向上的关节。
可配置关节（Configurable Joint）：自定义。
另：折断力 Break Force / 折断扭矩 Break Torque 是使关节折断需要的力/扭矩。
56. Cloth 组件有什么要注意的？
物理模拟包含刚体和柔体，柔体的运动会影响物体的自身形状，例如衣服、旗帜。
添加 Cloth 组件时会自动添加 Skinned Mesh Renderer。
固定方式：Cloth 中的 Edit Constraints → 单击 Select → 单击固定点（Shift 多选）→ 勾选 Max Distance 并输入距离。

第 6 章 粒子系统5 条

57. 什么是粒子系统？
粒子系统是由大量且微小的游戏对象组成的组合体，可模拟火焰、烟尘、瀑布。
58. 粒子系统三种数值设置？高频
① 权重：范围 0~1，例如 Attraction 的范围。
② 固定参数：固定一个参数，例如粒子发射器的持续时间。
③ 参数曲线：这是粒子系统可以千变万化的根源，通过对曲线的调变可以变化出各式各样的粒子效果。
59. 粒子模块分成哪六组？高频
① 基础模块 + Renderer 渲染模块
② 发射器模块：Emission 发射、Shape 形状、Sub Emitters 添加发射器
③ 粒子生命周期特效控制：Velocity / Limit Velocity / Force / Color / Size / Rotation over Lifetime
④ 粒子自身特效控制：Color / Size / Rotation by Speed、Texture Sheet Animation、Trails、Noise
⑤ 粒子与外界交互：Inherit Velocity、External Forces、Collision、Triggers、Lights
⑥ 自定义模块：Custom Data
60. over Lifetime 与 by Speed 的区别？高频
over LifeTime 模块：类似花开花落的一生（贯穿整个生命周期连续变化）。
by Speed 模块：类似跑龙套，当满足条件则执行（由速度触发）。
61. Shape 形状模块有哪些形状？Force Field 怎么用？
Shape 定义发射器的形状：球体 Sphere、半球体 Hemisphere、圆锥 Cone、立方体 Box、网格 Mesh。可沿着表面法线或随机方向施加初始力。
Particle System Force Field：粒子可通过其中指定的力（如风或吸引力）加速。要使用这个组件，需要开启粒子系统中的 External Forces（外力模块）。
包含：Shape（Start Range / End Range）、Direction(x,y,z)、Gravity（Strength 强度 / Focus 焦点）、Rotation（Speed / Attraction / Randomness）、Drag（拖拽）、Vector Field。
控制方式：基本粒子 ParticleSystem 用 Play + Stop；复合粒子 GameObject 用 SetActive(true/false)。

第 7 章 动画系统7 条

62. Mecanim 是什么？有什么特性？高频
Mecanim 是 Unity 推出的全新的动画系统，具有重定向、可融合等新特性。特性六条：
① 为类人角色设计简单的工作流；② 动画重定向能够把一个动画应用到多个不同模型；③ 用于对齐影片剪辑，简化工作流；④ 方便的影片剪辑预览、变换和交互；⑤ 使用可视化编程工具管理动画之间复杂的交互；⑥ 对身体不同地方使用不同的逻辑进行动画控制。
63. 两种角色配置有什么区别？模型有什么要求？
类人角色配置：Mecanim 对于类人角色有特别的工作流，使用扩展后的 GUI 和重定向，配置包含创建和设定 Avatar、调整肌肉定义等。
通用角色配置：为任何类人、四足动物之类设计的，不支持重定向。
模型要求：FBX 格式；尺寸 1.7~1.8；角色最底部与世界坐标的中心点对齐；模型要求 T Pose；骨盆位置的骨骼关节为所有骨骼的父层级；至少 15 个骨骼；烘焙后输出。
64. Avatar 是什么？有什么用？高频
Avatar 的创建过程就是分析导入的角色资源的骨骼结构，其过程是与 Mecanim 中已有的简化的标准人类骨骼进行对比，最后将其自动转化或标识为 Mecanim 可以识别的骨骼结构。
通过 Avatar 的创建，可以实现角色之间的 Retargeting。
组成：装配 + 肌肉。
65. 基本动画系统的四个制作步骤？
① 制作 Avatar 替身；② 设置动画状态机（Animator Controller）；③ 设置动画循环；④ 使用代码控制角色动画。
循环设置：start 改为 1，确保四个属性 LoopMatch 显示为绿色，勾选 Loop Time 和 Loop Pose、Bake Into Pose。
代码：animator.SetFloat("Speed", 1)、SetBool("IsRun", true)、SetLayerWeight(1, 1)。
66. 融合树（Blend Tree）是什么？高频
通过使用不同的角度将角色不同的部分混合，达到平滑动画的目的。为了使混合过后的动作起作用，必须混合造型和时间相近的动作。动画混合树在动画状态机中是一个特殊类型的状态。
做法要点：参数 Speed（Float） 和 Direction（Float）；子节点要加临界点 Threshold（先取消 Automate Threshold 勾选，设完再勾回来）。
67. 动画层与身体遮罩分别解决什么问题？高频
动画层：管理身体不同部分的复杂状态机，将不同部位的动画组合起来成为最后全身的动画效果。例如下半身层管走动/跑动，上半身层管投掷/射击。
身体遮罩（Avatar Mask）：对动画里面特定的身体部位进行激活或禁止，根据角色精确裁剪动画。例如双手举着物体时，手臂不能来回摆动，就做手臂遮罩。
权重：SetLayerWeight(1, 1)，权重 1 表示未被遮罩屏蔽的部分由该层骨骼动画控制，权重 0 表示不受该层影响。
68. 动画重定向（Retargeting）的原理？
Avatar 已配置模型的骨骼结构之间的对应关系，可以把相同的动画应用到各种角色模型上。
步骤：导入角色模型并附带 Avatar → 动画设计组件引用动画控制器资源 → 为角色编写脚本。

第 8 章 UGUI 界面9 条

69. uGUI 是什么时候推出的？有什么特点？高频
Unity 4.6 推出新的 UI——uGUI。特点：
① 与 Unity 无缝结合；② 强大易用的屏幕自适应；③ 简单的深度处理机制；④ 自动化的图集打包功能；⑤ 强大的布局系统，简单 UI 控件；⑥ 强大的事件处理系统。
命名空间：using UnityEngine.UI;
70. Canvas 的作用与两条注意点？高频
基础容器类控件，所有的 UI 控件必须位于画布之内，即必须是容器的子对象。
不能修改 XY 值，若需要修改，先设 RenderMode → World Space。
Pixel Perfect：像素更清晰。
注意 ①：UI 绘制顺序——如果两个 UI 元素位置重叠，后添加的元素会出现在新添加的元素前面。
注意 ②：默认会添加一个 EventSystem。
71. Canvas 的三种 Render Mode？高频
Screen Space – Overlay：UI 被渲染在屏幕上，一直显示在前面；屏幕大小或分辨率更改，画布自动更改以适配。
Screen Space – Camera：为 UI 指定一个相机，通过该相机呈现；可为 UI 增加粒子系统提升特效，Camera setting 会影响 UI 显示；Plane Distance 设置 UI 和 Camera 之间的距离；游戏相机 depth 是 −1，UI 相机 depth 是 0。
World Space：3D UI 模式，UI 类似一个 plane 对象，但 UI 不随相机移动而移动。
72. EventSystem 的作用与限制？
Event System：负责处理输入、射线投射以及发送事件，一个场景中只能有一个 EventSystem 组件。
Standalone Input Module：用于鼠标、键盘和控制器，被配置为查看 InputManager，基于 InputManager 的状态发送事件。
73. uGUI 的常用控件有哪些？
Canvas 画布、EventSystem、Panel 面板、Text 文本、Image 图像、RawImage 原始图像、Button 按钮、InputField 输入框、Slider 滑动条、Toggle 开关。
Panel：容器类控件，用于对一组控件的整体移动与管理。
74. Image 与 RawImage 的区别？高频
Raw Image 控件可以显示任何纹理，Image 只能显示一个精灵（Sprite）。
Image 导入图片后要设置图片属性为 Sprite（支持 PNG 透明）；SetNativeSize 设置原始大小；Preserve Aspect 保持原始比例。
ImageType：普通、切片、平铺、过滤填充。
RawImage 向用户显示非交互式图像，不能进行动画控制和填充控制。
75. Button 的可交互属性与事件怎么绑？
Interactable：是否可以交互（Click）。Transition：按钮按下等状态，Color Tint 多颜色覆盖、Sprite Swap 多图片、Animation 动画。
事件处理：① 将含公有方法的脚本添加到游戏对象 A 上；② 选择按钮，编辑 OnClick；③ 选择对象 A → 选择脚本中的处理方法。
76. 锚点（Anchor）与中心点（Pivot）分别是什么？高频
锚点：是相对于父容器的一种相对定位技术，是屏幕自适应的一种解决方案（雪花符号）。
中心点 Pivot：是控件本身进行各种旋转的位置依据（蓝色圆点）。修改方式：选中控件 → 选二维缩放工具 → 设置 Pivot，直接拖拽蓝色圆点（X、Y 值代表两个方向的比例）。
Rect Transform：用于 UI 空间的变换。
77. Slider 与 Toggle 怎么取值和做单选？
Slider：Value 属性；OnValueChanged 事件（处理函数带 float 参数表示 Value）；删除 Handle 后可以制作血条。
Toggle：Is On 属性表示是否选中；Group 属性做单选——创建空对象 G，为其添加 Toggle Group 组件，把多个 Toggle 的 Group 属性设为 G。
取值：GameObject.Find("Slider1").GetComponent<Slider>().value = 0.5f;

RenderSettings.skybox

附三、最后 3 小时只看这 15 条

  1. 游戏定义：直接获得快感（生理 + 心理）+ 主体参与互动（动作/语言/表情 + 刺激方式和程度）。
  2. 游戏引擎：已编写好的可编辑游戏系统 / 核心组件；技术栈 Game → Engine → SDK → DirectX/OpenGL → GPU。
  3. 三种管线：Built-in 低端原型 / URP 跨平台 / HDRP 3A 高清。
  4. 生命周期：Reset → Awake → OnEnable → Start → FixedUpdate → Update → LateUpdate → OnGUI → OnDisable → OnDestroy。
  5. LateUpdate 的原因：Update 顺序不可控，跟随者要等所有 Update 执行完再动，否则抖动。（但实验二代码写的是 Update——填空按原文，问原理才答 LateUpdate）
  6. 协程：不是线程；解决多帧协调；yield return 的值决定何时恢复。
  7. 天空盒三种：加相机组件 / RenderSettings.skybox（不能加组件）/ GetComponent<Skybox>.material（必须加组件）。
  8. 四种光源：Directional 太阳 / Point 灯泡 / Spot 手电 / Area 面光，Area 不能实时、只烘焙、物体必须静态。
  9. Bias：0~0.5；过小 self-shadow，过大阴影偏离物体。
  10. 叉乘：(y1z2−z1y2, z1x2−x1z2, x1y2−y1x2)；反交换律；求平面法线。
  11. 纹理 ⊂ 贴图 ⊂ 材质：纹理是数据，贴图是映射（UV），材质是数据集给渲染器用。
  12. 碰撞两层：检测 = 一个刚体 + 一个碰撞体；力作用 = 两个都刚体。
  13. Collision vs Trigger：Is Trigger 决定进哪个回调；发起方要有刚体；参数 Collision / Collider；阻挡 / 穿过。
  14. 物理材质是资源不是组件，赋给碰撞体的 Material 属性。
  15. 五种关节：Hinge 门 / Spring 松链接 / Fixed 附着 / Character 布娃娃 / Configurable 自定义。
