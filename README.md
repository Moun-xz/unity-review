## 01 · 复习手册

| 文件 | 内容 | 适合什么时候看 |
|---|---|---|
| `背诵手册.html` | 77 张知识卡片，覆盖 8 章 + 3 个附录。每张卡是一问一答，题源全部标注了课件页码或实验步骤 | 第一轮通读、考前默写 |
| `代码全解.html` | 41 段实验与课件真代码，逐句注释。从 C# 语法讲到 Unity API 的实际用法 | 编程题失分时对着补 |
| `组件属性速查清单.html` | 17 个组件、132 条属性。每条四栏：属性名 / 中文 / 作用 / **设错会怎样** | 案例题写不出「为什么」时 |

第三份的第四栏是重点。考试里真正的分差不在于知不知道 `Mass` 是什么，而在于能不能说出「Mass 设太小会怎样」。所以每一行都写了错误配置的后果。

## 02 · 模拟试卷

五套卷子，结构统一：

- **一、案例分析** 5 题 × 6 分 = 30 分
- **二、编程选择** 2 题，共 15 空 × 2 分 = 30 分
- **三、综合设计** 3 题 = 40 分（10 + 15 + 15）

| 卷次 | 特点 |
|---|---|
| 第一套、第二套 | 答案直接显示在题目下方，用来背 |
| 第三套、第四套、第五套 | 答案默认收起，点「看答案」原地展开，用来自查 |

五套之间没有重复考点：**75 个编程空互不相同**，25 道案例题覆盖 8 章，15 道设计题取自课程设计的 20 个选题。

设计题全部按「规则 → 机制 → 数值」三层组织。规则层说清玩什么、什么算赢；机制层给技术关键词；数值层给具体数字并解释为什么这么调。这套结构可以直接套用到任何一道设计题上。

速查表的用法不是通读，是**挑两道你最没把握的题，只看卡片写 120 字，写完对照技术词有没有漏**。写两道比读二十道有用。

## 04 · 真题复盘

`2026真题回忆版-参考答案.html` 是考后按记忆还原的整份试卷，外加逐题参考答案。

每题的结构是：题干 → 完整答案 → 绿色得分点清单。文末附了一张对照表，标出每道题的课件出处，以及这门课三轮考试里反复出现的规律：

1. 案例题的题库是固定的五块——美工、粒子特效、动画、地形、灯光声音
2. 编程题必定来自四个实验的源代码
3. 设计题必定来自课程设计的选题库，问法固定为「预制体 → 组件 → 怎么实现 → 业务逻辑」

需要说明的是：回忆版里的编程题原文代码没有完整还原，给出的 API 是按考点推测的，不是原始题干。

## 05 · 实验与课设工程

课程四个实验、三次作业与课程设计的 Unity 工程源码，按「实验 / 作业 / 课设」分类，只收录脚本、场景、预制体、材质、项目设置与自制资源；教学文档、素材包、第三方模型贴图和 Unity 缓存未收录。详见 [05-实验与课设工程/README.md](05-实验与课设工程/README.md)。

## 课程知识体系

| 章 | 内容 | 核心 API / 组件 |
|---|---|---|
| 1 | 概述、游戏引擎与开发流程 | — |
| 2 | C# 基础、面向对象、Update 与 FixedUpdate | `Time.deltaTime`、生命周期 |
| 3 | 场景搭建、地形、光源、音频 | `Terrain`、`Light`、`AudioSource`、`WindZone` |
| 4 | 3D 数学、向量与四元数、相机 | `Vector3`、`Quaternion.LookRotation`、`Slerp` |
| 5 | 物理系统、刚体、碰撞与触发 | `Rigidbody`、`Collider`、`Is Trigger`、`Physic Material` |
| 6 | 粒子系统 | `ParticleSystem` 各模块、`Sub Emitters` |
| 7 | 动画系统、融合树、动画层与身体蒙版 | `Animator`、`Avatar`、`Blend Tree`、`SetLayerWeight` |
| 8 | UGUI 界面 | `Canvas`、`RectTransform`、`Image Type`、`Toggle` |

三个容易混淆的点，单独记一下：

- `Update` 每帧调用，顺序不固定；`LateUpdate` 在所有 `Update` 之后，适合相机跟随
- 碰撞回调是 `OnCollisionEnter(Collision)`，触发回调是 `OnTriggerEnter(Collider)`，参数类型不同，写反了编译不报错但永远不触发
- 融合树是「一个状态」的内部结构，状态机是「多个状态」之间的关系，两者是包含关系，不是替代关系

## 怎么用这套资料

如果时间充裕（两周以上）：

```
背诵手册通读一遍  →  模拟卷第一、二套开卷做  →  代码全解补编程题

```
背诵手册的三个附录  →  五套卷的编程空过两遍  →  设计题速查表的 20 张卡片扫一遍

```
设计题速查表反面的「三层骨架」+ 五个案例方向各三句话
```
